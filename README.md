# Reserva IFRN — Página inicial

## Como abrir
1. Extraia a pasta `reserva_ifrn`.
2. Abra a pasta no Visual Studio Code.
3. Abra `index.html` no navegador (recomendado: extensão Live Server).

## Arquivos
- `index.html`: estrutura da página.
- `style.css`: identidade visual e responsividade.
- `script.js`: interação demonstrativa da senha e do formulário.
- `assets/caramujo.svg`: mascote vetorial reutilizável.

## Importante
A tela é somente um protótipo visual. O login ainda não está integrado ao SUAP; não digite uma senha real. A autenticação institucional e a integração com dados da lista exigem backend/API autorizada.
